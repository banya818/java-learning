## 编译 + 运行单个 Java 文件

```bash
cd C:/Users/ZhuanZ/java-learning
javac -encoding UTF-8 -d out src/day01/HelloWorld.java
java -Dstdout.encoding=UTF-8 -cp out HelloWorld
```

- `-encoding UTF-8` 防中文乱码
- `-d out` 把 .class 输出到 out 目录（已被 gitignore）
- `-Dstdout.encoding=UTF-8` 防控制台输出乱码

## 查看状态

```bash
git status              # 有哪些改动没提交
git log --oneline -5    # 最近 5 条提交
git remote -v           # 远程地址
```

## 洛谷提交清单

1. 类名必须是 **`Main`**
2. 不能有 `package` 声明
3. 不能有任何提示语（`System.out.println("请输入")` 一律删）
4. 输出要和样例**逐字符一致**：空格、标点、大小写
5. 边界值先自己试：0、1、最大值
