## 每天怎么提交

学完当天内容，在本目录打开终端（Git Bash），执行三条命令：

```bash
git add -A
git commit -m "day03 学了 if 和 for"
git push
```

或者用一键脚本，省事：

```bash
./commit.sh "day03 学了 if 和 for"
```
